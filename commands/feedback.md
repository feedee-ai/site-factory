Вход: `$ARGUMENTS` — ответ клиента на сообщение из `/new-site` шаг 7. Обычно расшифровка голосового: сумбурно, UA/RU вперемешку, с оговорками. Работаешь в репо клиента (не в site-factory). Цель — обновлённый сайт на проде без лишних вопросов Александру.

## 1. Записать как есть
`feedback/<YYYY-MM-DD>-<N>.md`, раздел «Ответ клиента»: текст дословно, ничего не правь.

## 2. Разобрать в решения (тот же файл)
- **Вердикт:** оставляем концепцию / переделываем с нуля / не сказал (тогда считай «оставляем»).
- **Правки:** таблица «что сказал (цитата) → что делаю (файл/секция) → тип (дизайн / тексты / структура / факты / фото)».
- **Факты:** цены, контакты, часы, доставка, имена → `site/assets/js/config.js`, тексты, schema.org; закрой пункты в «Открытые вопросы» проекта (`CLAUDE.md`).
- **Неясно:** только то, что без уточнения сделать нельзя.

Расплывчатое переводи в конкретное, не переспрашивая:
- «минималистичнее / проще» → меньше декора и цветовых полей, больше воздуха, меньше элементов в секции; мир сайта сохраняй.
- «покороче / много всего» → убери или слей секции с наименьшей ролью в продаже; hero, доказательства, заказ/запись и контакты не трогай.
- «шрифт не нравится» → смени пару шрифтов (с кириллицей, если нужна), иерархию оставь; «слишком мелко / крупно» → шкала.
- «цвет не тот / не наш» → бери из их брендовых материалов (лого, упаковка, интерьер, фото).
- «фото не те» → замени из `materials/`; нужного нет — попроси у Александра конкретные кадры.
- Что клиент похвалил — не трогай. Что не упомянул — не трогай.

## 3. Если «переделываем с нуля»
Сохрани текущую версию в ветке `v1` (push). Новая концепция по `/new-site` шаги 3–5 на тех же материалах; явно учти, что не понравилось, и не повторяй тот же мир. Планка из `/new-site` действует полностью.

## 4. Правки и проверка
Внеси всё одним заходом. Поменялась система (цвета, шрифты, компоненты) → обнови `DESIGN.md`. Проверка как в `/new-site` шаг 5, но по затронутым секциям + hero: 1440 и 390, консоль без ошибок, ссылка WhatsApp собирается правильно, нет горизонтального скролла. Один круг правок по скриншотам, не больше двух.

## 5. Публикация
Коммит `feedback N: <коротко>`, push в `main` (Vercel подключён к git → автодеплой). Проверь, что прод отдаёт 200 и изменения видны. Нет git-интеграции → `vercel deploy --prod` как в `/deploy`.

## 6. Ответ Александру (коротко)
- Ссылка на прод.
- Что сделано — по пунктам клиента, его же словами.
- Что не сделал и почему, вопросы из «Неясно» — одним сообщением.
- Готовое сообщение клиенту на его языке, от лица Александра: «обновили, вот что поменяли» (2–4 пункта), ссылка, «если что-то ещё, пишите или голосом». Без тире-«—».
